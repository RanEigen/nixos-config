# 本机代理

当前主机仅安装 Clash Verge Rev GUI。订阅、节点选择及代理启停由 GUI 管理；仓库不启用 dae、不配置本地 SOCKS 后端，也不注入全局代理环境变量。

## 使用方式

- 普通应用可使用 GUI 提供的系统代理模式；不需要手动给每个命令添加代理参数。
- 若要接管不遵循系统代理设置的应用，在 GUI 中尝试启用 TUN。TUN 的权限、DNS、IPv6、VPN/容器兼容性及停止后的路由清理均需在本机实测；仓库本身不声明特权代理服务。
- GUI 关闭或 TUN 未启动时，不应假设应用流量仍处于代理保护之下。
- `set -x http_proxy ...` 仅作用于当前 Fish 会话及其子进程。Nix daemon 是独立的 systemd 服务，不会继承该会话变量。
- Nix daemon 的流量也不再由 dae 透明接管。若需要通过 HTTP 代理下载，需单独为 daemon 配置环境，或使用已验证能接管该流量的 TUN 模式。

## 历史记录

此前曾由 dae 透明接管流量并转发到客户端 SOCKS 后端，也曾保留私有客户端的会话/托盘集成。这些配置现已从当前系统模块中移除；历史排障记录仅供追溯，不代表当前运行状态。
